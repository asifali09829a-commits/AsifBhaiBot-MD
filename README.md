# ⚡ AsifBhaiBot-MD

A WhatsApp bot for Termux powered by Node.js and Baileys.

## 📱 Termux Installation

Install Termux packages:

```bash
pkg update -y
pkg install -y git
git clone https://github.com/asifali09829a-commits/AsifBhaiBot-MD.git
cd AsifBhaiBot-MD
bash install.sh
npm start
## 🔐 WhatsApp Pairing

Open the dashboard in your browser:

http://127.0.0.1:3001

Use the pairing option to connect your WhatsApp number.

## ⚠️ Important

Do not share your auth_info folder.

WhatsApp session files are stored locally and are ignored by Git.
