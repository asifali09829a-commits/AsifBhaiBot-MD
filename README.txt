ASIFBHAI BOT

This is a lightweight starter dashboard that can run in Termux.
It is NOT a WhatsApp account hack and does not bypass WhatsApp security.

Termux:
  cd ~/AsifBhaiBot
  pkg install nodejs -y
  npm install
  npm start

Then open in the same phone browser:
  http://127.0.0.1:3000

The dashboard is designed in the style of the reference screenshot,
with AsifBhai branding, live status, stats and buttons.

For a real WhatsApp bot, connect an official/authorized WhatsApp API
or a WhatsApp Web library separately.
